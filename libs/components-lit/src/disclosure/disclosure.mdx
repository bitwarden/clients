## Connecting a trigger

- Plain HTML: wrap the trigger in `<bit-disclosure-trigger for="disclosure-id">`.
- Lit templates: `disclosureTriggerFor(disclosureElement)` on the trigger.
- Anything else: `attachDisclosureTrigger(trigger, disclosure)`, which returns a handle to
  `destroy()`.

Set `open` on `bit-disclosure` for its initial state (default closed). Toggling via the trigger
fires `openChange`.

## Accessibility

Follows the WAI-ARIA Disclosure (Show/Hide) pattern: the trigger gets `aria-expanded` and
`aria-controls`. For components whose button lives in a shadow root (e.g. `bit-icon-button`),
they're set on that inner button, using element reflection for `aria-controls` since ids don't
resolve across shadow roots. The trigger must be a button with an accessible label.
