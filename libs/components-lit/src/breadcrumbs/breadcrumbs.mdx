# Breadcrumbs

Breadcrumbs indicate the user's current location in a hierarchical structure of pages and let them
navigate back to parent pages.

<Primary />
<Controls />

## Links, buttons and the current page

A `bit-breadcrumb` with an `href` renders a link; without one it renders a button, so listen for
`click`. Mark the crumb for the current page with `current`: it renders as static text with
`aria-current="page"`. The active crumb should be the last one (see
[Breadcrumbs with page header](#breadcrumbs-with-page-header) for the exception). Set `current` from
your router; the stories here use a small hash router to demonstrate it.

```html
<bit-breadcrumbs>
  <bit-breadcrumb icon="bwi-vault" href="/vault">Vault</bit-breadcrumb>
  <bit-breadcrumb href="/vault/acme" current>ACME Corp</bit-breadcrumb>
</bit-breadcrumbs>
```

## Start slot

Slot a leading element into `start`, most commonly a `bit-icon-tile`. A slotted tile is sized with

## Sizes

Use `base` on large layouts and `small` in space-constrained contexts (narrow screens, the
extension).

## Overflow

When the trail doesn't fit, the first (root) and last (current page) crumbs stay anchored and the
crumbs between them move into a "More" menu after the root. Overflow is width-driven. **Declare
crumbs in path order, root first**: the crumbs nearest the current page collapse last. At very small
widths the root collapses too, and finally the current page truncates.

## Breadcrumbs with page header

Slotted into a `bit-header` (`slot="breadcrumbs"`), the `current` crumb renders as the page's `<h1>`
and the header suppresses its own title, through `HeaderContext`.

When the header shows the current page outside the breadcrumbs, set `show-trailing-arrow` to draw
one last arrow leading into the heading. Don't use it when the last crumb is the current page.

<Canvas of={stories.WithTrailingArrow} />

## Accessibility

- The host has `role="navigation"` with a localized label.
- Collapsed crumbs keep their semantics in the menu: a link stays a link.
- The "More" trigger has a localized label and only renders when something has collapsed.
