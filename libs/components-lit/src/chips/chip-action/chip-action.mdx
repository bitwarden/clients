Replaces `button[bit-chip-action]` and `a[bit-chip-action]`: the element renders a button, or a link
when `href` is set. Use a link when the chip navigates.

```html
<bit-chip-action label="Filter" start-icon="bwi-filter"></bit-chip-action>
<bit-chip-action label="View all" href="/items"></bit-chip-action>
```
