## Static

By default the avatar is non-interactive. Use it as an atom in a larger molecule like a list item,
table, or card. Static avatars have no hover or focus states.

## Interactive

Set `interactive` to render the avatar as a button, e.g. to open an account switcher menu. It has
hover and focus states, and supports `disabled`.

## Color

| Method         | Property    | Accepted values                                       |
| -------------- | ----------- | ----------------------------------------------------- |
| Default colors | `color`     | `"teal" \| "coral" \| "brand" \| "green" \| "purple"` |
| Custom color   | `color`     | CSS colors like a hex code                            |
| ID             | `avatar-id` | Unique string identifier                              |
| Text           | `text`      | The user's name; its first letters are displayed      |

## Accessibility

Avatar background color should have 3.1:1 contrast with its background. The accessible name is
`label`, falling back to `text`.
