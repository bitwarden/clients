# Section

Sections are simple containers that apply a responsive bottom margin and render a semantic `section`
element. Set `disable-margin` to remove the margin, e.g. on the last section of a page.

```html
<bit-section disable-margin>
  <div>Lots of amazing content!</div>
</bit-section>
```

## Section Header

Use `bit-section-header` inside `bit-section` for the heading.

### Padding

When the next sibling is (or contains) a `bit-card`, `bit-card-segmented` or `bit-item`, the header
adds bottom and inline padding to align with the card's border radius.

### Slots

| ------------ | ----------------------------------------------------------------- |
| default      | Title (usually an `h2` styled as h6) plus optional suffixes       |
| `slot="end"` | Placed at the end of the header, typically text or an icon button |
