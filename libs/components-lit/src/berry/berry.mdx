## Usage

### Status

Use a status berry to indicate a new notification or status change that is not related to a specific
count.

<Canvas of={stories.StatusType} />

### Count

Use a count berry to indicate item count information for multiple new notifications.

<Canvas of={stories.CountType} />

## Count Behavior

- Counts of **1-99**: Display in a compact circular shape
- Counts of **100+**: Display in a pill shape with padding

### Limiting displayed digits with `max-digits`

| `max-digits` | Cap threshold | Overflow display |
| ------------ | ------------- | ---------------- |
| `1`          | ≥ 10          | `9+`             |
| `2`          | ≥ 100         | `99+`            |
| `3`          | ≥ 1000        | `999+`           |

<Canvas of={stories.WithMaxDigits} />

## Accessibility

- Use berries as **supplemental visual indicators** alongside descriptive text
- For screen readers, provide labels on parent elements that describe the berry's meaning
- Important information should not rely solely on the berry color
