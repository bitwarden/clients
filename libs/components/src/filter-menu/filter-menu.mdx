# Filter Menu

A composable family of filter chips for narrowing a list or table.

<Canvas of={stories.Default} />

## Composition

A chip is single-select by default; add `multiple` for a checkbox-style multi-select.

```html
<bit-filter-menu key="type" placeholderText="Type" unsetLabel="All">
  <bit-filter-option [value]="'login'" [count]="12">Login</bit-filter-option>
  <bit-filter-option [value]="'card'" [count]="3">Card</bit-filter-option>
</bit-filter-menu>

<bit-filter-menu key="vault" placeholderText="Vault" multiple>
  <bit-filter-option [value]="'mine'" [count]="20">My vault</bit-filter-option>
  <bit-filter-option [value]="'acme'" [count]="11">Acme corporation</bit-filter-option>
</bit-filter-menu>
```

| Component            | Purpose                                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------------------------------- |
| `bit-filter-menu`    | Chip trigger + popover; owns the selection (`multiple` for multi).                                          |
| `bit-filter-toggle`  | Single on/off chip (no menu); boolean value; `iconActive` swaps the icon while active.                      |
| `bit-filter-option`  | A selectable row with a radio/checkbox indicator; shows a count in a table (or an explicit `count`). Nests. |
| `bit-filter-section` | A labelled, optionally collapsible group of options; shows a count berry of its selected options.           |
| `bit-filter-divider` | A vertical rule for separating groups of chips in the chip row.                                             |

## Nesting

Project `bit-filter-option`s inside one another to make an expandable parent. Selecting a parent
selects everything under it; a partly-selected parent renders indeterminate. Parents start
collapsed; add `expanded` to start one open. Requires `multiple` — a single-select chip holds one
value, so it throws if its options nest.

```html
<bit-filter-menu key="collection" placeholderText="Collections" multiple>
  <bit-filter-option [value]="'eng'" [count]="15" expanded>
    Engineering
    <bit-filter-option [value]="'monitoring'" [count]="20">Monitoring</bit-filter-option>
    <bit-filter-option [value]="'infra'" [count]="6">
      Infrastructure
      <bit-filter-option [value]="'cicd'" [count]="2">CI/CD</bit-filter-option>
    </bit-filter-option>
  </bit-filter-option>
</bit-filter-menu>
```

Nesting must be literal markup, or an inline `@for` per level; `ngTemplateOutlet` recursion does not
work.

## Value

A chip is a named form control. It owns its selection — **no `ngModel`** — and exposes it under its
`key`: a single value for single-select, an array for `multiple`. Sections group options for display
only; they all feed the chip's one selection.

The chip builds its label from the selected options (`placeholderText`, or
`placeholderText: unsetLabel` while empty). While active it shows a clear (`x`) on the chip; a
`multiple` chip also gets a sticky **Clear** button pinned to the bottom of its menu. Both reset the
selection.

## Icon tiles

An option can render a leading `bit-icon-tile` — pass an `iconTile` config and the chip draws it at
`size="xs"` so every row lines up.

```html
<bit-filter-menu key="type" placeholderText="Type" multiple>
  <bit-filter-option [value]="'login'" [iconTile]="{ icon: 'bwi-globe', variant: 'brand' }">
    Login
  </bit-filter-option>
</bit-filter-menu>
```

Usage guidelines:

- Use a tile on every option in a chip, or on none of them — a partial set leaves the labels ragged.
  On a single-select chip, remember the auto-injected "All" row has no tile.
- The tile is decorative; the option label carries the meaning, so no `ariaLabel` is applied.
- A disabled option's tile renders in the neutral `gray` family and ignores any custom `color`.

## In-menu search

Once a chip has more than ten options it renders a `bit-search` at the top of its own menu — you
never project a search field. It narrows the chip's options by their label: non-matching options
hide, a `bit-filter-section` collapses when all of its options are hidden, and a "no matching items"
message shows when nothing matches. The term resets when the menu closes.

## Driving a table

Chips are host-agnostic: on their own they just track their selection. Project one into a
`bit-table-v2` and it registers itself — its value lands in `table.filterValues()` under its `key`,
where the table's `filter(row, values)` reads it. See
[Table V2 › Filtering](?path=/docs/component-library-table-v2-beta--docs).
