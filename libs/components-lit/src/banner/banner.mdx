## Content Slots

- **Default slot**: plain text or inline elements, such as links.
- **`slot="actions"`**: only rendered when `heading` is set. Right-aligned at wide widths, below the
  body text at narrow widths. Match each button's `button-type` to the banner `variant`.

## Icons

Icons should remain consistent across these types. Do not change the icon without consulting
designers. Override the default with `icon`, or set `icon=""` to hide it.

## Dismissibility

The close button is only rendered when `dismissible` is set. Clicking it fires `dismiss`; the
consumer removes the banner.

<Canvas of={stories.NotDismissible} />

## Accessibility

Banners set `role="status"` and `aria-live="polite"` so screen readers announce their content. Set
`disable-alert-role` to turn this off.
