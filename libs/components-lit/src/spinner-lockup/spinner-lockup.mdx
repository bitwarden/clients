## Layout

- `horizontal` - Spinner and text side-by-side (default)
- `vertical` - Spinner above text, centered

## Variants and Sizes

All spinner variants (`primary`, `subtle`, `success`, `warning`, `danger`, `contrast`) and sizes
(`sm`, `md`, `base`, `lg`) are supported. Text scales with the spinner size.

## Content Slots

- `slot="title"` - Bold heading using the heading color
- `slot="description"` - Body text using the body color
