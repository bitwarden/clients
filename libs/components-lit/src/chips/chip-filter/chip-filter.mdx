## Options

Pass `ChipFilterOption<T>[]` to the `options` property. Nest options with `children`; the menu
navigates into them and offers "Back to …" and "View items in …".

```ts
html`<bit-chip-filter
  placeholder-text="Folder"
  placeholder-icon="bwi-folder"
  .options=${options}
  @change=${(e) => filter(e.target.value)}
></bit-chip-filter>`;
```

## Reading the current value

The chip is form-associated: read or set `value`, listen for `change`, or give it a `name` inside a
`<form>`.
