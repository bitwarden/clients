# Checkbox

`bit-checkbox` renders the box, label, hint and error (Angular `bit-form-control` + `bitCheckbox`).
It submits `value` (default `"on"`) under `name` while checked. `required` means it must be checked.
Set `card` (with optional `icon` or a `start` slot) for the card layout.

<Controls />

## Groups

Wrap checkboxes in `bit-form-control-group` for a legend and shared hint/error. Give the group a
`name` to submit the checked items' values and to validate it with `required`.
