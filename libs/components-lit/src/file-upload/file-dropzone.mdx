# File Dropzone

Drag-and-drop or click to pick files. `value` is a `File[]`; set it to pre-populate the list. With a
`name`, every file is a `FormData` entry. `accept` and `max-file-size` are hints, not validation.

## Accessibility

- Adding and removing files is announced assertively.
- The file input describes the current upload count, so users returning to it hear its state.
- After a removal, focus moves to the next delete button, or the dropzone when the list is empty.
