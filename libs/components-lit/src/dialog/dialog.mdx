# Dialog

Use this dialog when content exceeds 384px or has many interactive elements, e.g. the vault item
form. For alerts and confirmations, use the
[Simple Dialog](?path=/docs/component-library-dialogs-simple-dialog--docs).

<Primary />
<Controls />

## Slots

| Slot           | Description                       |
| -------------- | --------------------------------- |
| default        | body; scrolls when it overflows   |
| `title`        | extra heading content, e.g. badge |
| `header-start` | before the heading                |
| `header-end`   | before the close button           |
| `footer`       | actions                           |

## Size

`dialog-size` is `large` (48rem, for many interactive elements or tabs), `default` (36rem) or
`small` (24rem).

<Canvas of={stories.Large} />
